## Overview

This project demonstrates core HTML fundamentals by building a small recipe site with:
- A homepage that links to individual recipe pages
- Dedicated pages for Biryani, Pizza, and Burger recipes
- Basic styling with CSS

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone the repository (replace with your fork URL if needed):
   ```bash
   git clone https://github.com/<your-username>/odin-recipes.git
   ```
2. Open the project folder.
3. Launch `index.html` in your browser.
