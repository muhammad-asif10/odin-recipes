# Odin Recipes

A simple multi-page recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Overview

This project demonstrates core HTML fundamentals by building a small recipe site with:
- A homepage that links to individual recipe pages
- Dedicated pages for Biryani, Pizza, and Burger recipes
- Basic styling with CSS

## Built With

- HTML5
- CSS3

## Project Structure

```text
odin-recipes/
├── index.html
├── style.css
├── README.md
└── recipes/
    ├── biryani.html
    ├── pizza.html
    ├── burger.html
    ├── images/
    └── styles/
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/muhammad-asif10/odin-recipes.git
   ```
2. Open the project folder.
3. Launch `index.html` in your browser.
